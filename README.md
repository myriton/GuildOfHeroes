## Собственный проект

Тема проекта: Фильмы

Главный класс: Movies

Почему этот объект нужен программе: потому что вся предметная область проекта строится вокруг фильмов

Какие данные хранит объект:

- Name
- Genre
- Year
- Rating

Какие значения задаются через конструктор: все основные характеристики фильма: название, жанр, год выхода, оценка

Какие значения можно задавать автоматически: из этих 4, нельзя задать значения автоматически

## Практическая работа №2

### Поведение главного класса

Метод 1: AddScore
Что делает: добавляет новую оценку фильму и пересчитывает средний рейтинг

Почему эти действия относятся именно к этому классу: Рейтинг — характеристика самого фильма. Объект сам отвечает за корректность своего состояния при добавлении оценки, а внешний код только поручает действие конкретному фильму
